# Pallavi GNN and GCN AWS Implementation

This repository contains the practical implementation of GNN and Graph Convolutional Network (GCN) models executed in AWS EC2.

## AWS Environment

- Amazon EC2
- Amazon Linux 2023
- t3.large
- CPU execution
- Python 3.11
- PyTorch
- PyTorch Geometric

## Models

- Graph Neural Network (GNN)
- Graph Convolutional Network (GCN)

## Repository Contents

- practical/ - GNN and GCN implementation
- logs/ - execution logs
- results/ - AWS and experiment results
- outputs/ - generated outputs

AWS is used as the computational environment for execution and reproducibility.

Private keys, AWS credentials, ZIP archives and large sensitive datasets are excluded from this repository.
